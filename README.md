# US Momentum Terminal

Quantitative momentum ranking, portfolio construction, backtesting and an
append-only monthly track record for US equities in the S&P 1500
(S&P 500 + S&P MidCap 400 + S&P SmallCap 600).

Port of the NSE Momentum Terminal's strategy and website to the US market.
